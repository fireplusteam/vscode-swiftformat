# SwiftFormat for VS Code

This's a fork of [vkanabel](https://github.com/vknabel/vscode-swift-format) but the main difference that it supports formatting while typing like in Xcode without annoying removing of braces, trialing closures and other similar bugs while typing using original [vkanabel](https://github.com/vknabel/vscode-swift-format).

How to use this extension you can check on [vkanabel](https://github.com/vknabel/vscode-swift-format)
